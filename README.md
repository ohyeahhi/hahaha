# 동글마을

어른에게는 힐링, 아이에게는 배움(경제 → 영어)이 되는 동글동글한 마을 생활 게임입니다.

## 해보기

```bash
python3 -m http.server 8000
# 휴대폰이나 브라우저에서 http://localhost:8000/village/ 접속
```

- **땅 누르기:** 걸어가요. 손가락을 떼지 않고 누르고 있으면 그쪽으로 계속 걸어가고, 떼면 멈춰요. (키보드: 방향키 / WASD)
- **밭 누르기:** 씨앗 심기 → 물주기 → 수확
- **가게 누르기:** 오늘의 시세로 팔기, 씨앗 사기, 용돈기입장 보기
- **연못이나 낚시터 다리 누르기:** 낚시. 물고기가 물면 까만 막대가 초록 칸에 올 때 화면을 눌러요. 잡은 물고기는 도감(물고기 칸을 누르면 열려요)에 모여요.
- **집 누르기:** 집 안으로 들어가요. 꾸미기로 가구를 사고 놓을 수 있고, 저금통(하루 이자 5%)도 있어요. 침대를 누르면 잠자고 다음 날이 돼요.
- **과일나무 누르기:** 흔들어서 사과·복숭아·귤·배·체리를 따요. 45초마다 하나씩 다시 열려요.
- **곤충 누르기:** 살금살금 다가가서 잠자리채로 잡아요. 낮과 밤에 나오는 곤충이 달라요.
- **가방:** 모은 것을 보고, 과일과 채소를 먹으면 30초 동안 빨리 걸어요. 먹을 때는 동글이가 와구와구 먹는 모습이 크게 보여요.
- **음표 버튼:** 배경음악을 골라요. 오르골 산책, 창가의 피아노, 우쿨렐레 소풍, 빗소리 로파이, 별밤 자장가, 장터 가락 중에 고르거나 끌 수 있어요.
- **도감:** 채소·꽃, 과일, 물고기, 곤충, 음식을 모아요.
- **버스 정류장(마을 동쪽):** 7번 마을버스를 타고 동글시내에 가요. 교통카드 2코인, 코인이 없으면 걸어갈 수도 있어요.
- **동글시내:** 편의점(계산 알바), 분식집, 카페, 은행(하루 이자 8%), 붕어빵 노점이 있어요. 가게에서는 '사서 먹기'로 바로 먹거나 '담기'로 가방에 넣어요. 알바는 10·5·1코인 동전을 눌러 거스름돈을 직접 담아 드리는 놀이예요. 횡단보도는 초록불에만 건널 수 있어요.
- **지하철(동글시청역·한강공원역):** 2호선에 역이 셋(동글시장·동글시청·한강공원) 있어요. 내릴 역을 골라 타요. 한강에서는 낚시하고 한강라면을 먹을 수 있어요.
- **동글시장:** 청과물 가게와 수산 가게가 그날그날 마을 가게와 다른 값에 사 가요. "마을보다 ▲2"처럼 비교해서 더 좋은 곳에 팔고, 흥정하기를 눌러 보세요. 흥정은 사장님과 가위바위보! 이기면 청과물·수산 가게는 하나에 1코인씩 더 쳐주고, 떡집·반찬가게·방앗간·호떡 노점은 덤을 줘요.
- **몽글카페(시내):** 카페를 누르면 안으로 들어가요. 같은 게임 링크를 같은 시간에 연 친구들이 각자의 동글이로 보이고, 이름표가 붙어요. 왼쪽 아래 말하기 버튼으로 인사말이나 표정을 말풍선으로 보내고, 자리에 앉아 음료를 마시고, 친구를 누르면 하트를 보내요. 방명록에 한 줄과 스티커를 남기면 나중에 온 친구도 볼 수 있어요. 기본은 정해진 말만 주고받고, 직접 쓰기는 보호자 화면에서 켤 수 있어요. 함께 보기는 claude.ai에 올린 게임에서만 되고, 내 컴퓨터에서 열면 혼자 노는 카페(단골 손님 둘, 이 기기에만 저장되는 방명록)가 돼요.
- **동글도서관(시내):** 사서 동글이가 영어로 심부름을 부탁해요. 🔊 버튼으로 문장을 듣고, 물건을 가져다주면 코인과 함께 단어장에 영어 단어가 모여요. '듣고 고르기' 퀴즈에서는 영어를 듣고 맞는 그림(개수까지)을 골라요.
- **칭찬 도장판:** 알바, 영어 퀴즈, 도서관 심부름을 하루에 하나씩 마칠 때마다 도장을 받아요. 10개를 모으면 선물 상자(20코인)가 열려요.
- **사계절:** 4일마다 봄 → 여름 → 가을 → 겨울로 바뀌어요. 나무 색, 떨어지는 꽃잎·낙엽·눈, 제철 과일(빨리 다시 열려요), 계절마다 나오는 곤충이 달라요. 겨울에는 눈사람도 생겨요.
- **근처에 가면:** 화면 아래에 "물 주기", "낚시하기" 같은 버튼이 떠요.
- **EN 버튼:** 대화와 아이템 이름에 영어를 함께 보여줘요.
- **보호자 버튼(오른쪽 위 자물쇠):** 곱셈 문제로 어른인지 확인한 뒤 보호자 화면을 열어요. 아이가 번 돈·쓴 돈·저축 비율, 날마다 번 돈과 쓴 돈 그래프, 배운 경제 개념 8가지, 모은 영어 단어, 오늘 같이 나눌 대화 예시, 놀이 시간이 보여요. 쉬는 시간 알림(20·30·45·60분)을 켜면 시간이 됐을 때 마을이 멈추고, 어른이 확인해야 10분 더 놀 수 있어요.

저장은 브라우저에 자동으로 돼요.

## 폴더

- `village/`: 동글마을 시제품 (한 파일, 외부 라이브러리 없음)
- `docs/기획서.md`: 지금까지 정한 내용과 다음 단계
- `docs/art-reference/`: 캐릭터 원본 그림
- `village/assets/dongle/`: 원본 그림에서 오려낸 동글이 캐릭터 (게임에서 사용)
- `tools/cutout.py`: 배경이 단색인 사진에서 캐릭터를 오려내는 도구
  (`python tools/cutout.py docs/art-reference/coffee.webp village/assets/dongle coffee 280`, OpenCV 필요)
- `prototypes/clay3d/`: 3D 찰흙 캐릭터 실험
- `prototypes/fox-run/`: 첫 시험용 점프 러너 (미니게임 후보)
