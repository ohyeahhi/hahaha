# 동글마을

어른에게는 힐링, 아이에게는 배움(경제 → 영어)이 되는 동글동글한 마을 생활 게임입니다.

## 해보기

```bash
python3 -m http.server 8000
# 휴대폰이나 브라우저에서 http://localhost:8000/village/ 접속
```

- **땅 누르기:** 걸어가요. (키보드: 방향키 / WASD)
- **밭 누르기:** 씨앗 심기 → 물주기 → 수확
- **가게 누르기:** 오늘의 시세로 팔기, 씨앗 사기, 용돈기입장 보기
- **연못이나 낚시터 다리 누르기:** 낚시. 물고기가 물면 까만 막대가 초록 칸에 올 때 화면을 눌러요. 잡은 물고기는 도감(물고기 칸을 누르면 열려요)에 모여요.
- **집 누르기:** 집 안으로 들어가요. 꾸미기로 가구를 사고 놓을 수 있고, 저금통(하루 이자 5%)도 있어요. 침대를 누르면 잠자고 다음 날이 돼요.
- **과일나무 누르기:** 흔들어서 사과·복숭아·귤·배·체리를 따요. 45초마다 하나씩 다시 열려요.
- **곤충 누르기:** 살금살금 다가가서 잠자리채로 잡아요. 낮과 밤에 나오는 곤충이 달라요.
- **가방:** 모은 것을 보고, 과일과 채소를 먹으면 30초 동안 빨리 걸어요.
- **도감:** 채소·꽃, 과일, 물고기, 곤충 23가지를 모아요.
- **버스 정류장(마을 동쪽):** 7번 마을버스를 타고 동글시내에 가요. 교통카드 2코인, 코인이 없으면 걸어갈 수도 있어요.
- **동글시내:** 편의점(계산 알바), 분식집, 카페, 은행(하루 이자 8%), 붕어빵 노점이 있어요. 횡단보도는 초록불에만 건널 수 있어요.
- **지하철(동글시청역):** 2호선을 타고 한강공원에 가요. 한강에서 낚시하고 한강라면을 먹을 수 있어요.
- **근처에 가면:** 화면 아래에 "물 주기", "낚시하기" 같은 버튼이 떠요.
- **EN 버튼:** 대화와 아이템 이름에 영어를 함께 보여줘요.

저장은 브라우저에 자동으로 돼요.

## 폴더

- `village/`: 동글마을 시제품 (한 파일, 외부 라이브러리 없음)
- `docs/기획서.md`: 지금까지 정한 내용과 다음 단계
- `docs/art-reference/`: 캐릭터 원본 그림
- `village/assets/dongle/`: 원본 그림에서 오려낸 동글이 캐릭터 (게임에서 사용)
- `tools/cutout.py`: 배경이 단색인 사진에서 캐릭터를 오려내는 도구
  (`python tools/cutout.py docs/art-reference/coffee.webp village/assets/dongle coffee 280`, OpenCV 필요)
- `prototypes/clay3d/`: 3D 찰흙 캐릭터 실험
- `prototypes/fox-run/`: 첫 시험용 점프 러너 (미니게임 후보)
