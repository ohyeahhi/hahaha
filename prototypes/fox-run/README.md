# 여우 달리기 🦊

해 질 녘 언덕을 달리는 여우 점프 러너 게임입니다. 휴대폰 브라우저에서 바로 플레이하고, **홈 화면에 추가**하면 앱처럼 전체 화면으로 실행됩니다(PWA, 첫 방문 후 오프라인 지원).

## 조작
| 입력 | 동작 |
| --- | --- |
| 화면 탭 / 스페이스 / ↑ | 점프 |
| 공중에서 한 번 더 | 2단 점프 |
| P / Esc | 일시정지 |

- 바위와 그루터기는 뛰어넘고, 올빼미는 점프하지 말고 아래로 지나가세요.
- 산딸기는 개당 +10점. 달린 거리 10m마다 1점.
- 1500m마다 하늘이 오후 → 노을 → 밤 → 새벽으로 바뀌고, 점점 빨라집니다.

## 실행
```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```
GitHub Pages 등 HTTPS 정적 호스팅에 올리면 휴대폰에서 "홈 화면에 추가"로 설치할 수 있습니다.

## 파일
- `index.html` — 게임 전체 (Canvas + JavaScript, 외부 라이브러리 없음)
- `manifest.webmanifest`, `sw.js`, `icon.svg` — 앱 설치/오프라인용
